SUPPLIED ENGINEERING MODEL

Assumptions and calculation sequence

This development build implements Parts A and B of the supplied Theory and PRD, version 3.0. Its software checks do not replace the team's independent validation or review.

Atmosphere1976 standard atmosphere · geopotential altitude 0–11,000 m
Speed domainTrue airspeed · level-flight stall to Mach 0.30
PropulsionUseful power or thrust at the selected altitude; optional named piston lapse
PerformanceApproximate climb from level-flight drag; separate steady-glide force balance
Equations from Part A

(1) Atmosphere: T = T₀ + ah; p = p₀(T/T₀)−g₀/(aR); ρ = p/(RT); σ = ρ/ρ₀.

(2) Sound speed and weight: c = √(γRT); M = V/c; Vcap = 0.30c; W = mg₀.

(3)–(5) Aerodynamics: q = ½ρV²; CL = W/(qS); K = 1/(πeAR); CD = CD0 + KCL²; TR = D = qSCD; PR = DV.

(6)–(9) Propulsion and climb: propeller TA = PA/V; jet PA = TAV; ΔP = PA − PR; ΔT = TA − TR; deficit = max(PR − PA, 0); RC estimate = ΔP/W.

(10)–(14) Stall and minima: Vs = √(2W/(ρSCLmax)); A = ½ρSCD0; B = 2KW²/(ρS); VminT = (B/A)¼; VminP = (B/(3A))¼. Constrain each candidate to the supported speed interval before evaluation.

(15)–(19) Optima and intersections: CL,opt = √(CD0/K); unrestricted (L/D)max = 1/(2√(KCD0)). Solve F(V) = PA(V) − PR(V) = 0. Propeller maximum ΔP occurs at minimum PR; jet candidate V = √((TA + √(TA² + 12AB))/(6A)).

(20)–(22) Exact steady glide within this model: θg = atan(CD/CL); Vg = √(2W cos θg/(ρSCL)); sink = Vg sin θg; horizontal speed = Vg cos θg. Optimise over the glide coefficient domain, independently of the level-flight stall cutoff.

g₀ = 9.80665 m/s²; R = 287.05287 J/(kg·K); T₀ = 288.15 K; p₀ = 101325 Pa; a = −0.0065 K/m; γ = 1.4. No extra propeller efficiency is applied to useful power. Coefficients and configuration stay fixed within a run.
